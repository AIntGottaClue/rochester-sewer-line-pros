# Rochester Sewer Line Pros

Real Astro source for Rochester, New York. Single-source contact, request tracker and landing-page phone settings are in `src/data/siteConfig.ts`. No analytics is installed. Pages include local service copy, guides, neighborhood information, privacy, terms and three noindex ad landing pages. Build: `npm install` and `npm run build`. Cloudflare Pages output: `dist`.

The request success card follows a matching accepted tracker response; CRM arrival still needs separate confirmation. No municipal or contractor-license affiliation is claimed.
